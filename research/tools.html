Tools and Analysis Workflows

Reusable workflows for spectra, synthetic observations, and numerical-model outputs.

This page is for the research infrastructure behind the projects: analysis scripts, mock spectra, fitting workflows, and future public code. It is intentionally separate from the project pages so methods and tools can develop over time.

Workflow 01

ALMA spectral analysis workflow

A developing workflow for organizing ALMA targets, extracting spectra, normalizing continua, fitting absorption components, estimating uncertainties, and generating thesis-ready figures. The goal is to move away from one-off notebooks for each target and toward a more reproducible, configuration-driven analysis structure.

Workflow 02

Mock line-of-sight synthetic spectra

A numerical project that models how light from a background AGN continuum source is modified by intervening spherical gas clouds with varying optical depth, source function, covering fraction, velocity centroid, and velocity dispersion. The goal is to generate synthetic absorption spectra and test how cloud properties and instrumental resolution affect observable line profiles.

Workflow 03

Computational modeling background

My computational background includes modifying Fortran source code, running simulation suites on high-performance computing clusters, and analyzing numerical outputs with Python. This experience began in early Earth mantle evolution modeling and now informs how I think about simulation-based interpretations of AGN and quasar environments.
