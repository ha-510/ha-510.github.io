Tungsten-182 Isotopic Anomalies and Mantle Dynamics

Modeling early Earth mantle evolution using numerical simulations.

Status Completed research project
Mentors Bermingham · Boukaré
Methods Fortran · Python · HPC
Output Report · posters · manuscript in development

Project overview

Testing early Earth scenarios with numerical models.

This project investigated the origin of tungsten-182 isotopic anomalies observed in mantle-derived rocks. Under the mentorship of Prof. Katherine Bermingham and Prof. Charles-Édouard Boukaré, I used geodynamic simulations to test how late accretion, core–mantle interaction, silicate differentiation, and mantle mixing could affect the preservation and evolution of tungsten isotopic signatures over Earth history.

My role

Independent computational work under faculty guidance.

I worked independently between weekly faculty meetings to modify existing Fortran geodynamic code, run simulation suites on high-performance computing clusters, analyze mantle and crustal evolution outputs with Python, and prepare research materials for oral and poster presentations. This project trained me to test physical hypotheses by changing model assumptions, running the resulting simulations, and interpreting numerical output against observational constraints.

Methods

Simulation and analysis workflow.

  • Modified Fortran source code to implement alternative mantle evolution scenarios.
  • Ran large-scale simulations on Graham and Cedar high-performance computing clusters.
  • Analyzed simulation outputs using Python statistical routines.
  • Compared modeled tungsten-182 signatures with observational constraints from mantle-derived rocks.
  • Presented results through oral, poster, and research-group formats.

Technical contributions

Skills developed.

  • Scientific source-code modification in Fortran.
  • HPC job execution and file organization across simulation runs.
  • Python analysis of time-evolving model outputs.
  • Figure generation and statistical comparison of model behavior.
  • Translation of computational results into scientific presentations.

Relevance to astrophysics

Why this remains part of my research identity.

Although this project was in geochemistry and geodynamics, it remains central to my development as a researcher. It trained the habits required for simulation-based science: modifying code carefully, tracking model assumptions, running computational experiments, and comparing numerical outputs to physical constraints. Those skills now inform how I think about AGN environments, mock observations, and future numerical modeling of gas around quasars.
